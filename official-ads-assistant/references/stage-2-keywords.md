# 阶段 2：处理 Semrush 数据并生成精简投放关键词

收到 Semrush 关键词数据后，必须结合阶段 1 的落地页理解进行分析。

本阶段的目标是：

> 在保持品牌相关性、有效商业意图覆盖和流量可控性的前提下，通过近似变体去重与词组匹配归并，输出尽量精简、可解释、可直接投放的关键词清单。

不得将 Semrush 中每一个符合条件的搜索词，都直接转换成一个独立投放关键词。

本阶段只处理正向关键词，不输出最终否定关键词。

## 2.1 数据检查与清洗

分析前，先检查：

- Keyword、Volume、KD、CPC、Intent 等字段是否完整。
- 搜索量对应的国家或地区数据库、语言与时间范围是否明确。
- 是否存在完全重复、大小写差异、多余空格等重复数据。
- 是否存在同一品牌的单复数、常见错拼、拼写变体或等义词序变体。
- 是否存在不同产品、型号、套餐、地区或用户类型，需要保留独立意图。

处理规则：

- 保留原始搜索词，方便追溯。
- 用于去重的标准化处理，不得改变品牌名、产品名、型号或原始搜索意图。
- 缺失搜索量时，必须标记为“未知”，不得当作 0 或自行认定为低搜索量。
- Semrush 搜索量只能作为筛选参考，不得将其等同于实际可获得流量。
- 不得仅依据搜索量高低决定是否投放。
- 不得为缺失字段、归纳覆盖词或未提供的数据编造数值。

## 2.2 关键词意图分层与投放判断

必须识别以下类别：

- 核心品牌词。
- 品牌拼写变体。
- 品牌错拼词。
- 品牌词顺序变体。
- 品牌 + 产品或服务词。
- 品牌 + 高购买意图词。
- 品牌 + 价格、购买、商店、优惠、折扣、促销词。
- 品牌 + 官网、官方站点、品牌店词。
- 品牌 + 对比、替代方案词。
- 品牌 + 问题解决型商业词。
- 品牌 + 评论、评级、案例词。
- 品牌 + 登录、订单、客服、支持、退款、售后词。
- 信息型低转化词。
- 求职、招聘、职业相关词。
- 无关产品、无关人群、无关地区词。
- 竞品词。
- 非品牌词和泛类目词。
- 高风险或需要谨慎测试的词。

可以按“同一品牌 + 同一核心搜索意图 + 同一承接范围”组成词族进行分析，不要求每个原始搜索词都独立建词。

对每个词族说明：

- 搜索意图。
- 商业价值。
- 与落地页的相关性。
- 是否适合当前 Brand Campaign。
- 是否存在低质量、信息型或售后型流量风险。
- 处理方式：
  - 独立保留；
  - 近似变体合并；
  - 词组匹配归并；
  - 保留观察；
  - 不纳入。

非品牌词、竞品词、泛类目词和问题型关键词，继续遵守固定账户结构要求，不得混入当前最终投放关键词。

## 2.3 近似变体去重：默认只保留代表词

对于仅存在轻微表达差异、品牌指向和搜索意图相同的正向关键词，默认只保留一个代表词。

重点检查：

- 单数与复数。
- 常见错拼。
- 不改变品牌指向的轻微拼写差异。
- 不改变含义的词序变化。
- 不影响搜索意图的功能词增减。
- 其他具有充分理由判断为同意图近似变体的表达。

### 单复数去重示例

原始搜索词：

- brand promo code
- brand promo codes

默认只保留一个代表词，例如：

```text
[brand promo code]
```

不要仅因为存在复数形式，就额外添加：

```text
[brand promo codes]
```

如果该词族最终更适合使用词组匹配，则保留：

```text
"brand promo code"
```

不得再无理由重复添加其复数形式。

以上示例只说明去重方法，不代表必须同时保留该词的完全匹配和词组匹配。

### 代表词选择原则

- 优先使用准确、自然、常见的表达。
- 品牌词优先使用品牌标准拼写。
- 搜索量、商业价值和历史表现可作为辅助依据。
- 不得只因某个变体搜索量更高，就忽略其品牌歧义或落地页不匹配风险。
- 同一词族默认选择一个代表词，而不是将所有形式逐条保留。

### 不得机械合并的情况

以下情况需要单独判断：

- 实际指向不同品牌、产品、型号、套餐或服务。
- 词序变化导致含义变化。
- 缩写或错拼存在其他明确含义。
- 修饰词改变购买资格、产品范围、地区、优惠条件或用户类型。
- 已有实际搜索词数据证明，某个有价值变体需要独立保留。
- 单独保留具有明确的管理或投放价值。

所有被合并的原始词，必须在分析中记录归属，不得简单删除后不作说明。

不得声称保留一个代表词就能保证覆盖全部变体。覆盖关系应表述为合理预期，并在投放后结合搜索词报告验证。

## 2.4 低搜索量长尾词：优先评估词组匹配归并

对于搜索量较低、商业意图一致、具有共同规律的长尾搜索词，优先评估用一个带品牌的词组匹配关键词进行覆盖，而不是逐条添加完全匹配。

“低搜索量”应结合当前数据的整体分布判断，不设置适用于所有品牌和市场的统一阈值。

低搜索量本身不代表低价值。对于意图独立、落地页高度相关或已有转化价值的词，可以保留独立投放。

### 归并条件

同时满足以下条件，才建议归并：

- 指向同一品牌。
- 核心商业意图一致。
- 落地页能够承接该词族的主要需求。
- 差异主要来自非关键修饰词、表达方式或近似变体。
- 归并后不会明显扩大到不希望获取的搜索意图。
- 不会因删除必要限定词而改变产品、地区、资格或服务范围。

### 归并方法

1. 找出词族共同的品牌标识。
2. 找出共同的商业意图词。
3. 保留必要的产品、服务或范围限定词。
4. 选择一个足够简洁、但不会过度放宽意图的词组匹配关键词。
5. 将同一词族内的低量长尾词标记为“通过该词组匹配预期覆盖，不独立建词”。
6. 对无法合理归并、但具有独立价值的词，另行保留。

### 归并示例

假设以下词均与已核实的落地页优惠内容相关，且搜索量较低：

- brand promo code online
- brand promo codes online
- promo code for brand online

可优先评估归并为：

```text
"brand promo code"
```

不再默认逐条添加这些长尾词的完全匹配。

分析中应说明：

- 单复数差异按近似变体处理。
- 其余同意图表达通过该词组匹配预期覆盖。
- 不保证覆盖所有原始搜索词，投放后仍需验证。

### 必须遵守的边界

- 归并后的投放关键词必须保留明确的品牌标识。
- 不得将品牌优惠词归并成不带品牌的 `"promo code"`。
- 不得仅为减少数量，用一个过宽的品牌词组覆盖所有购买、登录、客服和售后意图。
- 不得机械合并不同产品、型号、地区、优惠资格或购买阶段的词。
- 不得假设 coupon、discount、promo code 等表达一定可以由一个词完整替代。
- 是否合并相近的商业表达，应结合实际含义、落地页承接范围和数据判断。
- 不得将词组匹配简单当作固定字符串包含规则，也不得据此保证所有长尾都会被覆盖。
- 归并后的关键词即使包含品牌，仍需在投放后检查实际搜索词是否偏离品牌意图。
- 如果缩短关键词会明显增加无关或售后型流量，应保留更具体的词组，或改用少量代表性完全匹配。
- 不得为了精简而默认改用广泛匹配。

### 归纳覆盖词的数据要求

如果归并后的词组并未直接出现在 Semrush 数据中：

- 可以作为由真实搜索词提炼的“归纳覆盖词”提出。
- 必须明确标记其来源。
- 必须说明它服务于哪个原始词族。
- 不得为其编造搜索量、CPC、KD 或其他数据。

## 2.5 匹配方式选择与重叠检查

每个最终保留的关键词必须给出建议匹配方式。

符号规则：

- 广泛匹配：`keyword`
- 词组匹配：`"keyword"`
- 完全匹配：`[keyword]`

### 完全匹配

优先用于：

- 核心品牌代表词。
- 意图独立、商业价值明确的品牌词。
- 需要更强流量控制的词。
- 不适合通过更宽词组归并的产品、型号或特定商业意图词。

不得因为选择完全匹配，就额外罗列所有单复数、常见错拼和其他没有独立价值的近似变体。

### 词组匹配

优先用于：

- 同一品牌下具有共同商业意图的词族。
- 可由同一核心词组承接的低搜索量长尾词。
- 在相关性和流量风险可控的前提下，需要覆盖多种表达方式的品牌商业意图词。

不得仅因某个词组更短，就认定它优于更具体的关键词。

### 广泛匹配

- 当前 Brand Campaign 默认不启用。
- 不得仅因为它能减少关键词条目就推荐使用。
- 只有在用户明确允许、转化追踪与出价条件适合、且有充分流量控制依据时，才可提出测试建议。
- 不得以广泛匹配替代必要的品牌相关性与搜索意图判断。

### 跨匹配方式去重

- 默认一个代表词只选择一种主要匹配方式。
- 不得机械地为同一个词同时添加广泛、词组和完全匹配。
- 如果已经选择词组匹配，不应再无理由添加同一词族的大量完全匹配长尾。
- 仅当存在明确的流量优先级、管理需求或已验证表现差异时，才可同时保留同一词的词组与完全匹配，并说明理由。
- 不得因为两个关键词含义接近，就直接认定其中一个完全没有独立价值。
- 不设置固定关键词数量上限。
- 以“最少必要数量”而非“越少越好”为原则。

## 2.6 分析结果输出要求

依次输出以下内容。

### 数据概览

简短说明：

- 原始关键词数量。
- 数据完整性与主要限制。
- 主要品牌搜索意图。
- 近似变体与低量长尾的主要分布。

仅在数据足够时输出数量，不得编造统计结果。

### 关键词意图与投放判断

按类别或词族说明：

- 搜索意图。
- 商业价值。
- 落地页相关性。
- 流量风险。
- 投放或处理结论。

无需为每一个相似原始词重复同样的解释。

### 关键词精简与覆盖说明

建议使用以下字段展示归并结果：

| 原始词或词族 | 保留的投放关键词 | 匹配方式 | 合并处理 | 保留或合并理由 |
|---|---|---|---|---|

要求：

- 明确哪些词属于近似变体去重。
- 明确哪些低量长尾通过词组匹配归并。
- 明确哪些词因独立价值需要单独保留。
- 合并覆盖关系须可追溯。
- 数据较多时可以按词族展示，并列出代表性原始词。
- 不得将多个搜索词的搜索量简单相加，就宣称为去重后的可覆盖流量。
- 不得把“删除不相关词”和“合并有效关键词”混为同一种精简结果。
- 如提供精简前后数量，必须说明统计口径。

### 四类投放结论

保留以下分类：

- 必投核心品牌词。
- 建议测试的品牌商业意图词。
- 可谨慎测试的其他高意图品牌词。
- 不建议投放但暂不在本阶段处理为否定词的词。

每个独立保留的投放关键词必须标明匹配方式。

“已通过其他关键词归并覆盖、不独立建词”的原始词，应单独说明，不得误列为“不建议投放”。

最终可复制清单只纳入当前方案明确建议实际启用的关键词。仅供观察、尚需用户确认或暂不启用的词，不得混入最终代码块。

## 中文关键词格式要求

如果关键词包含中文，必须遵循以下规则：

- 中文品牌名、中文产品名、中文词组内部不得加空格。
- 正确：`品牌官网`
- 正确：`品牌名优惠`
- 正确：`品牌名价格`
- 错误：`品 牌 名 优 惠`
- 如果搜索词自然包含多个完整词，可以保留词与词之间的空格。
- 正确：`品牌名 官网`
- 正确：`品牌名 产品名称`
- 正确：`Brand Name 官网`
- 不得因关键词匹配符号而破坏中文词语结构。
- 词组匹配和完全匹配中的中文关键词同样不得拆字。

## 最终可复制投放关键词

在分析说明后，必须额外输出《最终可复制投放关键词》区域。

输出前，必须再次完成：

1. 完全重复检查。
2. 单复数、常见错拼和等义词序等近似变体检查。
3. 低量长尾词组归并检查。
4. 同一代表词跨匹配方式重复检查。
5. 品牌相关性检查。
6. 独立搜索意图与必要限定词检查。
7. 落地页承接能力检查。

### 输出规则

- 关键词和否定关键词必须完全分开。
- 本阶段只输出建议实际启用的正向关键词。
- 本阶段不得输出最终否定关键词。
- 一行一个关键词。
- 不要编号。
- 不要表格。
- 不要重复。
- 必须保留正确的匹配方式符号。
- 不得使用 Broad Match Modifier。
- 不得混入暂不建议投放、竞品词、泛类目词或非品牌词。
- 不得混入登录、客服、订单、售后、招聘等低质量词。
- 已归并覆盖的近似变体和低量长尾，不得再次无理由单独加入。
- 广泛匹配单独使用一个代码块，词组匹配和完全匹配共用另一个代码块，先列词组匹配，再列完全匹配。任一区块没有关键词时，省略对应标题和代码块。
- 不得为凑齐三种匹配方式而添加关键词。
- 代码块中不得放入解释、占位符或“无”等非关键词内容。

使用以下格式。示例仅用于说明匹配符号，实际输出必须替换为已筛选的真实关键词；空区块必须省略。

### 最终可复制投放关键词

#### Broad Match
```text
brand product
```

#### Phrase and Exact Match
```text
"brand promo code"
[brand]
```

完成阶段 2 后，不得生成否定关键词。
