# 1. 分析产品线并推荐 ASIN

确认品牌名和目标国家。收集 Semrush 品牌相关关键词、联盟后台产品清单、可用的交易记录（如有）和卖家精灵商品列表数据。

缺少卖家精灵商品列表时，先确认亚马逊品牌名和国家，缺少任一项就向用户询问后再启动。筛选关键词可选。把品牌、国家、用户提供的筛选条件和指定工作目录交给「小助手-卖家精灵」子技能，并按以下约定委托：

> 先检查最近一周内是否有同品牌、同国家的商品清单。若已有记录覆盖本次筛选范围，直接引用该记录，无需再次调用 MCP。否则只调用卖家精灵 MCP 商品列表查询，按品牌、国家和用户提供的条件筛选。按站点货币筛选当前价格，美元 ≥ 50、欧元 ≥ 40、英镑 ≥ 40。逐页取完所有匹配商品。若分页失败或无法确认完整性，说明缺口。
>
> 交付 Markdown 表格文件。保留 MCP 返回的所有字段和值，移除 sellerNation 和 sellerName。核对 ASIN、标题、品牌、BSR、货币、月销量、月销售额、评论数、子体销量档位、子体销售额、评分、徽章、是否畅销体和上架时间。若接口缺字段，注明缺失。小数四舍五入到一位。月销量口径 representative_variant 简写为 r_v，并在备注中说明它表示代表变体口径。
>
> 文件名为「卖家精灵-{品牌名}-{国家代码}-{年月日 时分秒}.md」。保存到指定工作目录，未指定时保存到 /Users/yao/Downloads/AI-Agent/SellerSpriteMCP/。返回 Markdown 文件路径或已有记录引用，并注明商品数和完整性。

消费子技能交付的 Markdown 文件或引用，不要求转换成 CSV。子技能无法调用或清单不完整时，请用户提供对应品牌和站点的商品列表以补齐。交易记录缺失时，继续用现有数据分析。

按产品线归组，给出代表关键词，并关联可匹配的交易记录。按产品线汇总展示、点击、加购、花费、佣金、CPC、ROI 和加购率。注明统计周期、计算口径以及实测、估算或缺失状态。汇总后计算比率，分母为零或缺失时标为不可计算。把代表关键词作为选品依据。

按增量规则第七至十节核对售价和联盟可投条件。上述站点币种门槛优先于增量规则中的统一 $50 门槛，其余联盟可投条件、缺失值和例外按原文处理。给出主推产品线、推荐理由及 5～8 个代表 ASIN。合格候选不足时列出实际候选并说明原因。交付到选品为止，等待用户发起第二阶段。
